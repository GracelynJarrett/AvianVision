AvianVision Project Log

**About This Document**
This document serves as the official daily and weekly log for the AvianVision capstone project. 
Its purpose is to track progress, document challenges, and maintain a clear record of decisions 
made throughout the project lifecycle.

**How to use this document:**
- At the start of each day, fill in the Day Goal before doing any work
- At the end of each day, complete the remaining daily fields and write the Summary paragraph
- At the end of each week, complete the Week Review section before planning the next week
- Be honest — if something didn't get done or a challenge came up, document it. This log is 
  for your benefit and your professor's visibility, not just for show
- Any changes made to project files, the project plan, or scope should always be noted in 
  the Summary paragraph so there is a clear record of why things changed
